プライバシーポリシー（kodomo-no-ne-yoyaku）

制定日：2026年11月8日

1. この道具について

「kodomo-no-ne-yoyaku」（以下「この道具」）は、YouTube チャンネル「こどものね」の運営者が、自分のチャンネルに動画を上げて公開日を予約するためだけに使うものです。運営者以外の方が使うことはありません。

2. 使う情報

この道具は、YouTube API サービスを使い、運営者が許可した YouTube アカウントについて、次のことだけを行います。

  • 動画を上げる・タイトルや説明文、公開日などの設定を入れる
  • サムネイルを入れる・再生リストに入れる
  • 上げた動画の設定（公開日・子ども向けの設定など）を確かめる
  • 許可したチャンネルの名前を確かめる

視聴者の方の情報を集めたり、読み取ったりすることはありません。

3. 保存と共有

許可のための情報（トークン）は、運営者のパソコンの中だけに保存します。第三者に渡したり、売ったり、上に書いた目的のほかに使ったりすることはありません。

この道具による Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

4. 許可の取り消し

許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。取り消すと、この道具は YouTube アカウントに触れられなくなります。

5. YouTube と Google の規約

この道具は YouTube API サービスを使っています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。

6. お問い合わせ

このポリシーについてのお問い合わせは、YouTube チャンネル「こどものね」の概要欄からお願いします。
